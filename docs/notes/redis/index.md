# Redis

## 简介

Redis（Remote Dictionary Server）是一个基于内存的高性能键值数据库，支持丰富的数据结构和多种应用场景。

**核心特性：**
- **高性能**：基于内存存储，支持每秒数十万次读写操作
- **丰富的数据结构**：支持字符串、列表、哈希、集合、有序集合等
- **持久化支持**：提供 RDB 和 AOF 两种持久化方式
- **高可用性**：支持主从复制、哨兵模式和集群部署
- **多种应用场景**：缓存、消息队列、分布式锁、排行榜等

Redis 最初用于解决数据库访问压力问题，通过将热点数据存储在内存中，减少磁盘数据库访问，提高系统响应速度和吞吐能力。随着互联网应用的发展，Redis 已经不仅仅是一个缓存工具，而是逐渐成为后端系统中不可或缺的基础组件。
